# Santino Brocato | Portafolio Personal

Portafolio web personal enfocado en desarrollo web a medida.

## Tecnologías Utilizadas

- **HTML5 Semántico**: Para una estructura accesible y buena indexación SEO.
- **Vanilla CSS**: Estilos a medida, sistema de diseño basado en variables (`:root`), modo oscuro y animaciones sutiles.
- **Vanilla JavaScript**: Funcionalidad ligera para menú lateral (sidebar), scroll suave y carga progresiva (IntersectionObserver) sin dependencias externas.

## Características

- 📱 Totalmente responsivo (Mobile-first a Desktop).
- 🎨 Diseño moderno con paleta de colores oscuro (Dark Mode).
- ✨ Animaciones suaves e interacciones premium (micro-interacciones, hover effects).
- ⚡ 100% libre de frameworks pesados, carga instantánea.

## Cómo ejecutar localmente

1. Clonar el repositorio.
2. Abrir el archivo `index.html` en el navegador, o usar un servidor local ligero:
   ```bash
   python3 -m http.server 8080
   ```
3. Visitar `http://localhost:8080`.
