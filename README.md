## 📖 Sobre el Proyecto

Este portafolio ha sido construido desde cero (100% *Vanilla*) enfocándose en el rendimiento, la accesibilidad y un diseño moderno e impactante. La arquitectura de diseño prioriza el minimalismo y el alto contraste ("Dark Mode"), empleando micro-interacciones para generar una experiencia de usuario envolvente sin sacrificar velocidad de carga.

### ✨ Características Principales

- **Diseño "Vibecoded" (Vanilla Tech Stack):** Construido sin frameworks pesados, garantizando tiempos de carga ultrarrápidos.
- **Sistema de Diseño Flexible:** Basado enteramente en variables CSS (`:root`) para escalabilidad y fácil mantenimiento.
- **Scroll Animado (IntersectionObserver):** Los elementos aparecen suavemente a medida que el usuario hace scroll, guiando la atención visual.
- **Arquitectura Responsiva:** Diseñado "Mobile-first" para adaptarse a cualquier resolución (Smartphones, Tablets y Escritorio).
- **Glassmorphism & Micro-interacciones:** Elementos visuales modernos con efectos de desenfoque, transiciones sutiles e iconos vectoriales integrados.

## 🚀 Cómo ejecutar localmente

Si deseas explorar el código o hacer un fork, el proceso es muy sencillo ya que no requiere dependencias:

1. **Clona el repositorio:**
   ```bash
   git clone https://github.com/BrocatoSantino/mi-portafolio.git
   ```

2. **Navega al directorio:**
   ```bash
   cd mi-portafolio
   ```

3. **Inicia un servidor local:**
   Puedes abrir `index.html` directamente en tu navegador, o usar un servidor (recomendado para cargar ciertos recursos sin bloqueos CORS):
   ```bash
   python3 -m http.server 8080
   ```

4. **Visualiza el sitio:**
   Abre [http://localhost:8080](http://localhost:8080) en tu navegador.
